# Team Roles & Responsibilities

## Purpose

This document defines the responsibilities of every team member in the SIH26 engineering team. Every member is expected to contribute actively, communicate regularly, and deliver assigned tasks on time.

---

# Team Lead

## Responsibilities

- Define project vision and roadmap.
- Coordinate the team.
- Break down work into tasks.
- Assign responsibilities.
- Review pull requests.
- Resolve technical blockers.
- Ensure deadlines are met.
- Make final architectural decisions.

## Expectations

- Strong communication.
- Good technical understanding.
- Leadership and decision making.
- Availability for meetings.

# Responsibilities of Every Member

Every team member must:

- Attend scheduled meetings.
- Complete assigned tasks before deadlines.
- Use Git correctly.
- Create Pull Requests for all changes.
- Review teammates' code when requested.
- Communicate blockers early.
- Keep documentation updated.
- Respect team members.
- Maintain professionalism.

---

# Contribution Policy

Every contribution should:

- Follow coding standards.
- Include meaningful commit messages.
- Be tested before submission.
- Include documentation when necessary.
- Be submitted through Pull Requests.

We aim to build software with professional engineering practices rather than treating this as a college project. Every member is responsible for maintaining quality, collaboration, and continuous improvement throughout the Smart India Hackathon journey.
